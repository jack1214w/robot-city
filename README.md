# 機器人蓋城市 Robot City

給 2～7 位學生在**同一個大螢幕**上輪流出牌（或各自用**平板**出牌）的運算思維體驗遊戲。改編自桌遊《Robot City 機器人蓋城市 v2》。

學生用「控制卡」規劃機器人在電路板城市上的移動路線，搶奪木頭、鐵礦、石頭、沙子四種原料，蓋出任務卡上的建築物換取積分。四種控制卡分別對應程式的四大結構，每張卡下方都印著對應的程式碼。

**線上試玩**：https://jack1214w.github.io/robot-city/

---

## 怎麼用

單一 HTML 檔，**不需要伺服器、不需要安裝、不需要網路**（只有字型會連 Google Fonts，離線時自動退回系統字型）。

- 直接下載 `index.html` 雙擊開啟，或
- 開上面的線上網址

建議用筆電接投影機／電視，學生輪流上台或接手滑鼠出牌。

開場畫面三選一：**單人練習** ／ **多人對戰（單機熱椅）** ／ **多人對戰（平板連線）**。前兩種就是上面說的單一檔案，平板連線見下一節。

## 平板連線模式

每個學生用**自己的平板**看手牌、排程式，**看不到彼此的手牌**；投影只放地圖、計分板、執行紀錄與回合引導。
走教室區網，**不需要任何雲端服務或帳號，學生資料不出教室**。

### 老師上課時要做的事

1. 在 robot-city 資料夾**雙擊「平板連線-啟動.command」**——會開一個黑色視窗（伺服器），並自動打開投影畫面
2. 開場畫面已經選好「多人對戰（平板連線）」，設定好人數與規則，按 **開房**
3. 投影上出現大大的 **QR code**，學生用平板掃碼、點自己的座位（1 號機～7 號機）
4. 全部到齊後按 **開始遊戲**

第一次執行時 macOS 可能跳防火牆詢問視窗，按「允許」。下課後關掉黑色視窗即可。
筆電上要有 Node.js（`node --version` 看得到版本就有）。

### 上課時會發生的事

| 狀況 | 會怎樣 |
|---|---|
| **還沒輪到的學生** | 可以**先在自己的平板上把程式排好**（執行鍵是鎖住的）。輪到他時自動放進程式區，可以再改也可以直接執行 |
| 學生排程式時 | 投影上程式區只顯示「蓋著的牌」，按下執行才公開，全班一起看機器人跑 |
| 執行中要選目標（專車接送、交換、病毒、路障、分配資源） | 在**出牌那位的平板**上選；投影顯示「等 X 號機選擇… 30 秒」 |
| 學生 30 秒都沒選 | 系統代選預設值（不傳送、不交換、不偷、資源自動分配），遊戲不會卡住 |
| 平板斷線（鎖屏、Wi-Fi 晃一下） | 計分板標「斷線」；網路恢復後**自動接回原座位** |
| 學生不小心重新整理平板 | **自動回到原座位**，不用重掃。平板記得自己的座位（只記這一間房） |
| 學生被排到別人的座位 | 平板在等待畫面上有「不是我的座位，重新選」 |
| 老師重新整理投影畫面／再玩一局 | 平板會等老師重新開房，**自動回到原座位**，不用重掃 |
| 上一堂課留下的舊 QR code | 每次啟動房號都會換，舊的掃進來會提示「已經過期」 |

### 等待時可以先排程式

學生還沒輪到自己的時候，手牌是可以點的，排出來的程式放在自己的「預排區」：

- 程式區標題變成 **預排中 / PRE-PLAN**，底色打上斜線，下面有一行說明
- **執行鍵鎖住**，清空鍵可以用；迴圈的 ＋／− 照常，可以先把包夾排好
- 輪到自己時自動接進程式區，執行紀錄會寫一行「等待時先排好的 N 張已經放進程式區」
- 投影上**看不到別人排了什麼**，只會顯示「已經有 N 位先把下一輪的程式排好了」
- 老師按暫停時，預排也跟著停

> 預排是**對目前盤面**排的。等輪到你，別人可能已經把資源撿走、或在你前面放了路障——
> 這時候要自己改。這件事值得在課堂上講一次，它本身就是「計畫趕不上變化」的教學點。

### 老師手上的兩個按鈕（投影畫面右上）

| 按鈕 | 做什麼 |
|---|---|
| **暫停／繼續** | 所有平板立刻停住，顯示「老師暫停了」，誰都不能出牌；回合計時也一起停。要講話、要處理狀況時用 |
| **跳過這回合** | 直接換下一位。排好的卡**留在手上**，不算出過——和「時間到」的處理方式一樣。會先問一次要不要 |

> 學生正在平板上選格子／選人的那 30 秒內按不了暫停，畫面會告訴你還剩幾秒。
> 這是刻意的：暫停一個已經問出去的選擇，會讓學生點了沒反應，比等一下更難處理。

### 網路或設備出狀況時

隨時可以切回**單機熱椅**：開場選「多人對戰（單機熱椅）」，不需要網路，跟以前一樣。

## 單人練習

第一次接觸的學生可以先自己打一場，把規則和節奏摸熟再上桌對戰。

- 一個人挑戰，開場先看一頁「挑戰說明」：這次有幾回合、幾分拿幾顆星、三個最容易忽略的重點
- 在限定回合內（6 / 10 / 15）盡量拿分，回合用完或資源被撿光就結算
- 結算給 **★ 星等評價**與分數拆解，並記住**最佳紀錄**（存在瀏覽器本機），下次超越會標示新紀錄
- 需要對手才有意義的卡（交換卡、病毒、路障，以及「周圍有／沒有對手」的綠卡）不會出現在單人牌堆裡

## 每回合時間限制

避免有人卡太久拖慢全班。設定「30 / 45 / 60 秒」後，畫面最上方會出現倒數，剩 15 秒轉黃、剩 5 秒轉紅。

時間到就強制結束該回合，規則是明確的：

- 還沒按「執行」的指令 **不會動作**，卡片留在手上
- 正在執行中的動作 **會做完**，後面的指令才停下
- 已經撿到的資源自動分配到任務卡

看規則說明的時候倒數會暫停。

## 控制卡與程式結構

| 卡色 | 程式結構 | 內容 |
|---|---|---|
| ⬜ 白 | 循序 `move(1)` `turn(90)` | 前進、左轉、右轉、迴轉 |
| 🟨 黃 | 重複 `repeat(3){ }` | **自己決定夾住哪幾張**，整段重複跑 |
| 🟩 綠 | 選擇 `if(wall3){ clear(3) }` | **「如果⋯就⋯」整句印在一張卡上**，動作由系統隨機派給，條件不成立整張跳過 |
| 🟧🟥 橘＋紅 | 呼叫副程式 `call( … )` | 專車接送、交換卡、磁鐵、病毒、加速器、**炸彈、鑽頭、路障**；紅卡必須排成「橘 → 紅 → 橘」才會生效 |

只開白卡＝純粹的循序指令，適合第一次接觸；四種全開＝完整的運算思維四大結構。

## 黃卡的迴圈：Scratch 式的包夾

黃卡放進程式區後會長出一個**凹槽**，用卡片右下角的 **＋ ／ −** 決定要把下面哪幾張夾進去，中間的數字就是目前夾住幾張。

這一點很關鍵：同樣是「重複 ×2、左轉、左轉」，

- 夾 **1 張** → 左轉兩次後再左轉一次，共 **3 次**
- 夾 **2 張** → 左轉 **4 次**

夾住的範圍不同，結果完全不同——這正是學生要學會自己掌控的地方。凹槽裡還能再放一張黃卡形成**巢狀**（`重複×2` 裡夾一個 `重複×3` ＝ 做 6 次）。

## 綠卡：如果⋯就⋯

綠卡是**一張卡講完一整句判斷**：上面是條件，下面「→ 就⋯」是條件成立時自動執行的動作。

```
IF
如果 前方 3 格有障礙
→ 就 清掉前方 3 格的障礙
if(wall3){ clear(3) }
```

- 內建的動作是**系統隨機派牌**的，玩家不能自己指定。學生能決定的是「要不要用這張、放在程式的第幾步」
- 條件**成立就做**，**不成立整張跳過**，執行紀錄會寫出判斷結果是「是」還是「否」
- 牌組只收**搭得起來**的組合，不會出現「如果前方是障礙 → 前進 3 格」這種永遠做不到的卡
- 綠卡本身是一張普通單卡，**可以被黃卡夾進迴圈**，每一圈都重新判斷一次條件

目前 12 種組合：

| 條件 | 內建動作 |
|---|---|
| 前方可通行 | 前進 3／前進 2 |
| 前方有資源 | 前進 1 |
| 前方 3 格有資源 | 前進 3／吸走四周的資源 |
| 前方走不通 | 右轉／迴轉 |
| 前方是障礙 | 炸掉前方的障礙 |
| 前方 3 格有障礙 | 清掉前方 3 格的障礙 |
| 周圍有對手（九宮格） | 迴轉／清掉前方 3 格的障礙 |
| 周圍沒對手（九宮格） | 前進 3 |

## 紅卡特殊能力

全部都要排成「橘 → 紅 → 橘」才會生效。

| 卡片 | 效果 |
|---|---|
| 專車接送 | 瞬間移動到地圖上任一空格 |
| 交換卡 | 與任一位玩家交換位置 |
| 磁鐵 | 吸走上下左右四格的資源 |
| 病毒 | 偷走一位玩家已收集的 1 個資源 |
| 加速器 | 直線衝刺，最多前進 4 格 |
| **炸彈** | 炸掉上下左右四格的障礙物 |
| **鑽頭** | 鑽過前方的障礙物，停在它後面 |
| **路障** | 在地圖上任選一個空格放下障礙物（會切斷通路的格子點不下去） |

## 課堂輔助

- **回合引導橫幅**：畫面最上方一直顯示「現在輪到誰、可以做什麼」，並在紅卡沒被橘卡夾住時主動提醒。
- **執行紀錄**：機器人每一步都逐行印出來（含迴圈跑到第幾次、條件判斷是或否），方便帶著全班一起除錯。
- **座標**：地圖有 A–N / 1–9 座標，學生可以直接口頭說「機器人在 C4」。
- **可收合版面**：每個面板都能縮小；整欄收起時地圖會自動放大。上方「專注地圖」可一鍵全部收合。
- **看別人的任務卡**：點計分板上的玩家即可查看，計分板的「差 N」是該玩家最接近完成的一張還缺幾個資源。
- **輪到誰一眼看得出來**：目前玩家的機器人有白金雙圈與脈動環，腳下的格子會亮起來，座標軸也會標出所在的行與列。

## 計分

- 完成的任務卡：拿卡片上的完整積分
- 未完成的任務卡：上面已收集的資源，每個算 1 分
- 暫存卡：**不計分**（所以要記得用「2 換 1」換成需要的資源）

## 技術

遊戲本身仍是單一 `index.html`，熱椅與單人模式不需要伺服器。平板連線多了一支只用 Node 內建模組寫的小伺服器 `tools/live/server.js`（不需要 `npm install`），它只負責送網頁與轉傳訊息，遊戲規則全部在老師筆電的網頁裡跑。

單一檔案，無相依套件、無建置流程。原生 HTML / CSS / JavaScript，支援淺色與深色主題。要修改直接編輯 `index.html` 即可。
