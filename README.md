# 機器人蓋城市 Robot City

給 5～7 位學生在**同一個大螢幕**上輪流出牌的運算思維體驗遊戲。改編自桌遊《Robot City 機器人蓋城市 v2》。

學生用「控制卡」規劃機器人在電路板城市上的移動路線，搶奪木頭、鐵礦、石頭、沙子四種原料，蓋出任務卡上的建築物換取積分。四種控制卡分別對應程式的四大結構，每張卡下方都印著對應的程式碼。

**線上試玩**：https://jack1214w.github.io/robot-city/

---

## 怎麼用

單一 HTML 檔，**不需要伺服器、不需要安裝、不需要網路**（只有字型會連 Google Fonts，離線時自動退回系統字型）。

- 直接下載 `index.html` 雙擊開啟，或
- 開上面的線上網址

建議用筆電接投影機／電視，學生輪流上台或接手滑鼠出牌。

## 課堂設定（開場畫面全部可調）

| 項目 | 選項 |
|---|---|
| 人數 | 5 / 6 / 7 人，可自訂姓名 |
| 地圖 | 小 6×9 / 中 8×11 / 大 9×14 |
| 資源密度 | 少 / 中 / 多（選「資源搶光」結束時，這項直接決定遊戲長度） |
| 任務卡 | 每人同時持有 2 或 3 張 |
| 目標積分 | 4～20 分 |
| 結束條件 | 積分達標 / 資源搶光 / 兩者先到 |
| 程式區格數 | 每回合最多出 4 / 5 / 6 張 |
| 執行速度 | 慢 / 中 / 快 |
| **開放的控制卡** | 依學生程度勾選，白卡固定開啟 |

## 控制卡與程式結構

| 卡色 | 程式結構 | 內容 |
|---|---|---|
| ⬜ 白 | 循序 `move(1)` `turn(90)` | 前進、左轉、右轉、迴轉 |
| 🟨 黃 | 重複 `repeat(3){2}` | 把接下來 N 張卡包起來，重複跑幾次 |
| 🟩 綠 | 選擇 `if(hasItem)` | 判斷地圖狀況，是 → 做 A，否 → 做 B |
| 🟧🟥 橘＋紅 | 呼叫副程式 `call( … )` | 專車接送、交換卡、磁鐵、病毒、加速器；紅卡必須排成「橘 → 紅 → 橘」才會生效 |

只開白卡＝純粹的循序指令，適合第一次接觸；四種全開＝完整的運算思維四大結構。

## 課堂輔助

- **回合引導橫幅**：畫面最上方一直顯示「現在輪到誰、可以做什麼」，並在紅卡沒被橘卡夾住時主動提醒。
- **執行紀錄**：機器人每一步都逐行印出來（含迴圈跑到第幾次、條件判斷是或否），方便帶著全班一起除錯。
- **座標**：地圖有 A–N / 1–9 座標，學生可以直接口頭說「機器人在 C4」。
- **可收合版面**：每個面板都能縮小；整欄收起時地圖會自動放大。上方「專注地圖」可一鍵全部收合。
- **看別人的任務卡**：點計分板上的玩家即可查看，計分板的「差 N」是該玩家最接近完成的一張還缺幾個資源。

## 計分

- 完成的任務卡：拿卡片上的完整積分
- 未完成的任務卡：上面已收集的資源，每個算 1 分
- 暫存卡：**不計分**（所以要記得用「2 換 1」換成需要的資源）

## 技術

單一檔案，無相依套件、無建置流程。原生 HTML / CSS / JavaScript，支援淺色與深色主題。要修改直接編輯 `index.html` 即可。
